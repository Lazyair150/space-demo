# 05 · 测试计划（2026-11-17 现状）

所有自动化测试都是 `SceneTree` 脚本，headless 跑，不进游戏包、不影响玩家：

```bash
GODOT="/d/godot/Godot_v4.7.1-stable_mono_win64/godot.exe"
"$GODOT" --headless --path . --script res://tests/industrial/<脚本>.gd
```

| 脚本 | 覆盖 | 断言数 |
| --- | --- | --- |
| `bridge_smoke.gd` | Bridge 契约：装配/坏配置拒绝/词表/主从台/派单/可行性/分步执行/帧流/暂停/回合上限/重置 | 35 |
| `runtime_smoke.gd` | 时间映射：累积器、单帧最多 1 刻、积压截断与上报、暂停、失焦冻结、帧率无关 | 26 |
| `ui_smoke.gd` | 界面：结构、推进、换台、派单（随机/模板）、刷新不丢状态、关界面仍生产、投矿提速、材料强化、报价卡、执行中锁定、不可行二层清单 | 57 |
| `scene_switch.gd` | 真实场景切换：菜单 ↔ 工业舱、世界存活、残骸掉矿 | 12 |
| `reward_smoke.gd` | 奖励：发奖幂等、材料换攻击力、上限、重开后仍可发奖 | 17 |
| `save_smoke.gd` | 存档：世界（回合/工单/仓库/主从台）与钱包读回、读档不补算、坏档退回新局 | 19 |
| `full_loop.gd` | 全链路：菜单→工业派单结算→强化→保存→战斗伤害/掉矿→读档 | 15 |
| `tests/hud_feedback.gd` | 战斗 HUD：获得提示（只报增量）、目标提示随材料档位切换、满级文案、结束复原钱包（`persist_wallet=false`） | 15 |
| `segment_smoke.gd` | 段落化波次：五波段落名顺序、各段刷怪数、精英数值放大、喘息不刷怪 | 17 |
| `ui_capture.gd` | 非测试：带窗口跑一遍并截图到 `tmp/ui_capture/`（headless 抓不到画面） | — |

## 人工验收清单（未经自动化覆盖）

1. 带窗口进工业舱，看着产线卡「累加」数字一格格涨，按「推进一回合」确认仓库/装配台按预期变化。
2. 打一场战斗，看 HUD 的「矿石」「攻击」是否随残骸/强化变化，伤害是否体感不同。
3. 从菜单进工业舱 → 返回 → 再进，确认是同一局而不是重开。
