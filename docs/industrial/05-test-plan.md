```bash

"$GODOT" --headless --path . --script res://tests/industrial/<脚本>.gd
```

## 人工验收清单（未经自动化覆盖）

1. 带窗口进工业舱，看着产线卡「累加」数字一格格涨，按「推进一回合」确认仓库/装配台按预期变化。
2. 打一场战斗，看 HUD 的「矿石」「攻击」是否随残骸/强化变化，伤害是否体感不同。
3. 从菜单进工业舱 → 返回 → 再进，确认是同一局而不是重开。
