# Space Concept Sprite Library

All files are editable SVG source assets. They are concept silhouettes, not yet wired to collision scenes or animation state machines.

| Asset | Role |
|---|---|
| `ship_player_frigate.svg` | Player starter frigate |
| `enemy_scout.svg` | Fast light enemy |
| `enemy_bomber.svg` | Heavy/ranged enemy |
| `enemy_elite_warden.svg` | Elite / boss-family silhouette |
| `asteroid_iron.svg` | Iron asteroid / arena obstacle |
| `energy_stone_small.svg` | Small energy stone pickup |
| `energy_stone_large.svg` | Large high-volume energy stone |
| `rift_gate.svg` | Sector transition / rift entrance |
| `relay_station.svg` | Mission objective / relay structure |
| `support_drone.svg` | Support ability unit |
| `jar_offense.svg` | Offense-category Jar concept, angular triangle mark |
| `jar_defense.svg` | Defense-category Jar concept, shield mark |
| `jar_support.svg` | Support-category Jar concept, circular mark |
| `jar_recon.svg` | Reconnaissance-category Jar concept, diamond mark |
| `jar_utility.svg` | Utility-category Jar concept, square mark |

Art direction: deep navy base, cyan/ice highlights for player technology, amber energy accents, red-magenta enemy language. Keep the silhouette readable at 32 px and preserve generous negative space. The five Jar silhouettes visually echo the five Space ability categories; they are presentation concepts only and do not hardcode shape vocabulary into Jar Core. These are the first concept batch; final animation, hitbox and damage-state variants remain scene-level work.
